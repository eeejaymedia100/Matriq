Download the Android app (APK)

If Android asks, allow your browser to install unknown apps — Matriq isn't on the Play Store yet, so this is the official way to install it.

  1. Tap Download above and let the file finish downloading.
  2. Open the notification and tap the downloaded file.
  3. If prompted, tap Settings and allow Install unknown apps for your browser.
  4. Tap Install, then Open and sign in.
